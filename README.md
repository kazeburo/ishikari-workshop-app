# くるくる画像工房

小中学生の障害調査・復旧体験向けの、ブラウザとGoサーバのアプリです。お絵かき・写真・カメラ画像をサーバに送り、万華鏡またはモザイクタイル画像に変換します。モザイクタイルは目地と縁の光・影を付けて陶器のタイル風に加工する効果で、複数の写真を組み合わせるフォトモザイクではありません。

## 起動

Go 1.22以降で、以下を実行します。外部ライブラリは使いません。

```sh
go run . -addr :8080
```

ノートPCから `http://サーバのIPアドレス:8080` を開きます。同じPCで起動した場合は `http://localhost:8080` です。サーバとノートPCの通信ができ、TCP 8080が許可されている必要があります。インターネット接続は不要です。

配布用の実行ファイルを作る場合:

```sh
go build -o image-workshop .
./image-workshop -addr :8080
```

画面・画像変換はすべて実行ファイルに含まれます。配布先にはGoのインストールも不要です。Linux/amd64サーバ用に別のPCでビルドする例:

```sh
GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -o image-workshop-linux-amd64 .
```

## お手本と背景

「お手本・背景」から、カラフルな丸・花畑・熱帯魚、または石狩の雪景色・星空・海の中を選び、「キャンバスに使う」を押します。そのまま変換したり、上から絵を描いて変換したりできます。すべて画面に組み込まれているため、カメラや写真ファイルがなくても利用できます。

## カメラについて

ブラウザのカメラは、通常HTTPSまたはlocalhostでのみ利用できます。別のサーバのIPアドレスにHTTP接続する構成では、写真の選択とお絵かきを利用してください。OSのカメラアプリで撮影し、その写真を選ぶ方法も使えます。

ブラウザ内で撮影する場合は、各ノートPCで信頼される証明書を事前に用意してHTTPSで起動します。証明書はアクセスするホスト名またはIPアドレスに対応するものが必要です。自己署名証明書の警告を通過するだけではカメラが使えるとは限りません。イベント前に実機で確認してください。

```sh
./image-workshop -addr :8443 -cert server.crt -key server.key
```

HTTPSも外部ネットワークへの接続は不要です。

## 体験の流れ

1. チームで絵を描くか写真を選び、変換して作品を保存します。
2. スタッフが体験用サーバのプロセスを止める、または体験用ネットワークを切断します。
3. 開いた画面では引き続き絵が描けますが、サーバでの変換は失敗します。サーバの接続表示も変わります。
4. チームで原因を調べ、復旧します。
5. 同じ画面から変換を再実行し、作品が届くことを確認します。

障害中はブラウザのタブを開いたままにしてください。画面自体もサーバから配信するため、障害中の再読み込みや新規アクセスでは画面を取得できません。復旧後は自動で接続表示が戻り、変換を再試行できます。変換待ち時間の上限は12秒です。接続表示は4秒間隔で確認します。接続表示が正常でも変換機能の正常性までは保証しないため、作品を作って復旧確認をしてください。

画像は640×640に収め、余白を白で埋めて送信します。万華鏡は中心からの角度を折り返して模様を作り、モザイクタイルは各タイルの平均色に、明るい目地と縁の立体的な光・影を加えます。入力画像と結果はサーバのファイルに保存せず、メモリ上で処理します。画像や写真の内容はログに記録しません。ブラウザ上の入力・作品は再読み込みで消えるため、必要な作品は保存してください。

体験用の閉じたネットワーク向けです。認証や大量アクセス対策は含みません。APIはPNG/JPEG、最大8MB・2048×2048まで受け付けます。
